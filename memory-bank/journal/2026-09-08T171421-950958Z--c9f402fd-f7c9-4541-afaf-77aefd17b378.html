Fixed rke2_preflight control-plane label selector

Detailsroles/rke2_preflight/tasks/main.yml selected -l node-role.kubernetes.io/control-plane,node-role.kubernetes.io/master. A comma in a kubectl label selector is AND, and RKE2 1.36 dropped the deprecated master label, so it matched zero nodes and aborted preflight against a fully healthy control plane. Now selects control-plane alone, consistent with add_servers_rke2.yml and remove_nodes_rke2.yml. Affects any RKE2 1.36+ cluster, selassie included.
