Post-upgrade version assertion no longer passes vacuously

Detailsupgrade_rke2.yml asserted `node_versions_raw.stdout is search(target_kubelet_version)`: a substring match over every node's output at once, so it passed when only one node had reached the target. The target also came from hostvars[groups.rke2_servers[0]].rke2_target_version, undefined under --limit, defaulting to '' and making search('') always true. It now derives the target from any host that ran version_check, fails when it cannot be determined, and requires every line to match. Also corrected a wrong comment: kubeletVersion DOES carry the +rke2r1 suffix on RKE2 1.36, so the match accepts both bare and suffixed forms.
