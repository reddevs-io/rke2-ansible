any_errors_fatal on server play only, not agents

RationaleA failed server mid-run risks etcd quorum loss if the next server proceeds; a failed agent is recoverable. Applying any_errors_fatal to both would halt the run on any single agent failure, which is overly strict for worker pools.
Implementation DetailsFix #12 sets any_errors_fatal: true on the server play only. Agent play keeps current behavior. Open question flagged for operator in case they want agents to halt-on-first-failure too.
